    OptimizationRunSettings

    Bases: BaseAlbertModel

    Settings for a model-guided optimization design run.

    All fields are optional; omit a field (or pass None) to use the platform default for that knob. Values outside the allowed ranges are rejected before the run is submitted.

    Notes

    These two settings work together: candidate generation produces up to num_candidates_generated candidates, then the top num_candidates_selected diverse formulations are kept as the result batch.

    Show JSON schema:
